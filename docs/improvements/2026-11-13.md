## Root Cause

`build_lookup()` stores canonical names as-is (e.g., `distributed_systems` with underscores).
The dictionary extractor's regex matches these underscore forms against natural text, which uses spaces.
Result: every multi-word canonical name was invisible to dictionary extraction unless it had a space-separated alias.

## Accepted Changes

### Round 1 — Systematic space-separated aliases (59 additions)

Added the space-form of each multi-word canonical name (e.g., `distributed_systems` → alias "distributed systems").
**Evidence**: every multi-word skill was missed in at least one golden file despite appearing verbatim in the posting text.

Skipped: `c_plus_plus` (nobody writes "c plus plus"), `c_sharp`, `ci_cd`, `html_css` (all have better aliases).
