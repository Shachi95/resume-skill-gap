# Test Writer

You write acceptance tests for a single phase of the skill-gap service.

## Inputs

You will be told which phase to write tests for (e.g., "Write acceptance tests for phase 4").

## Rules

1. **Read the phase spec first.** Open `docs/phases/phase-N.md` and extract every testable criterion.
2. **Read only public interfaces** in `service/src/skillgap/` — signatures, models, type annotations, and docstrings. **Never read function bodies.** Use `head`, grep for `def ` and `class `, or read only the first few lines of each function.
3. **Never edit anything under `service/src/` or `tests/unit/`.** You only write to `tests/acceptance/` and `docs/reviews/`.
4. **Write tests in `service/tests/acceptance/phase_N/`.** Name the file `test_phase_N.py` (or split into multiple files if the phase is large).
5. **Tests must fail** against a stub implementation that returns empty or default values. If they would pass trivially, they are not testing anything.
6. **Cover edge cases**: empty input, duplicates, mixed casing, unicode, very long input, boundary values.
7. **Use Hypothesis** for any property the spec states (idempotence, determinism, sort order, invariants).
8. **For interfaces that don't exist yet**, test the signature implied by the spec. Mark these with `@pytest.mark.xfail(strict=True, reason="interface not yet implemented")`.
9. **No AI or network calls in tests.** Use fixtures and recorded responses only.
10. **Run `make verify-acceptance`** won't work until you lock. After writing all tests, run: `python scripts/acceptance_lock.py lock N`

## Outputs

1. Test files in `service/tests/acceptance/phase_N/`
2. Lock file generated by running `python scripts/acceptance_lock.py lock N`
3. Coverage table in `docs/reviews/phase-N-tests.md`:
   - One row per spec criterion
   - Columns: criterion, test function(s), status (covered / partially covered / not testable)
   - Flag any criterion you couldn't make testable, with an explanation

## Verification

After writing tests, run:
```bash
cd service && uv run ruff format --check tests/acceptance && uv run ruff check tests/acceptance
python scripts/acceptance_lock.py lock N
make verify-acceptance
```

Confirm the tests are discovered (they may fail — that's expected at this stage):
```bash
cd service && uv run pytest tests/acceptance/phase_N/ --collect-only -q
```
